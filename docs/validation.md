# 验证记录

目标协议为 RPC v7、middleware v6、scheduler v3，宿主版本声明为 `>=3.41.0`

Rustfmt、严格 Clippy 与 27 个插件行为/RPC 测试通过，Linux x86_64 发行包由官方 CLI 生成。宿主相关的 10 个容量与亲和合同测试通过

发行包内可执行文件通过同一套六项 RPC 验收，归档与包内文件摘要一致。页面 ESLint、类型检查、生产构建、Actionlint 和 Shell 语法检查通过，前端生产依赖审计未发现已知漏洞

本地检查覆盖以下行为：

- 选号等待达到阈值后申请可用账号，阈值前委托严格绑定
- 同会话迁移意图串行化，实际取得新账号后重置其他等待者的阈值
- 上游执行时间不计入后续尝试的账号选择等待
- 候选失效、日志保存失败与请求取消后的协调位置释放
- 原生续写、引用输入与预热保护，缺少身份时不推测会话
- 切换意图、实际取得账号与改绑证据分离，跨请求或跨尝试证据不混用
- 576 条记录跨索引页完整保留、服务端分页、精确版本冲突及进程重启后的历史读取
- 真实插件子进程与受控宿主的 RPC 交互、诊断读取和取消流程
- 宿主配额耗尽、记录正文写入失败、索引提交失败及不重放选号的恢复
- 设置输入不完整或包含未知字段时，在调用原生接口前拒绝
