# 验证记录

目标协议为 RPC v7、middleware v6、scheduler v3，宿主版本声明为 `>=3.41.0`

Rustfmt、严格 Clippy 与 25 个插件行为/RPC 测试通过，Linux x86_64 发行包由官方 CLI 生成。宿主相关的 10 个容量与亲和合同测试通过

发行包内可执行文件通过同一套三项 RPC 验收，归档与包内文件摘要一致。页面 ESLint、类型检查、生产构建、Actionlint 和 Shell 语法检查通过，前端生产依赖审计未发现已知漏洞

本地检查覆盖以下行为：

- 选号等待达到阈值后申请可用账号，阈值前委托严格绑定
- 同会话迁移意图串行化，实际取得新账号后重置其他等待者的阈值
- 上游执行时间不计入后续尝试的账号选择等待
- 候选失效、日志保存失败与请求取消后的协调位置释放
- 原生续写、引用输入与预热保护，缺少身份时不推测会话
- 切换意图、实际取得账号与改绑证据分离，跨请求或跨尝试证据不混用
- 私有状态幂等追加、保留上限和进程重启后的历史读取
- 真实插件子进程与受控宿主的 RPC 交互、诊断读取和取消流程

CPR 3.41.0 官方 Linux 发行包配合隔离 PostgreSQL、Redis 完成真实安装和浏览器验证：

- 运行状态为 `running`，从宿主左侧插件导航打开页面，通过实际管理桥查询历史
- 请求 ID 查询、改绑结果筛选、分页、展开收起详情、重置与键盘 Enter 查询
- 浅色、深色主题同步和 390 像素窄屏，表格局部横向滚动，无页面横向溢出
- 空结果、加载状态、受控读取失败、保留原列表和重试恢复，无浏览器脚本异常
- 从 0.1.0 升级至 0.2.0，原有 5 秒配置与 23 条测试记录均保留，手动改为 15 秒后显示当前值
