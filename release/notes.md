# v0.3.0

- 扩展页可直接修改等待阈值，并编辑三个阶段的开关、执行顺序、失败处理及请求范围，与 CPR 原生插件设置共用配置
- 移除默认 200 条、最多 500 条和整份历史 240 KiB 的保留限制，逐条保存并通过服务端分页查询，不自动删除旧记录
- 历史写入使用精确版本检查，未完成的写入单独显示，达到宿主存储配额时保留已有记录并停止本次主动迁移

升级保留已有等待阈值与历史，旧 `historyLimit` 不再参与保留策略，保存设置后从配置中移除。默认等待仍为 15 秒，计时为账号选择等待，不检测上游首输出

宿主私有状态仍有每命名空间 16 MiB、10,000 个状态对象和单值 256 KiB 的实际配额。新版历史写入后，旧包缺少新状态命名空间，CPR 可能拒绝直接回退，升级前备份私有数据

宿主范围保持 `>=3.41.0`，提供 Linux x86_64 安装包，要求 glibc `>=2.34`
